## Featured project

### MadrigueritApp

Cross-platform household management product for **iOS, Android and Web**.

It combines shared tasks, calendar events, shopping, expenses and household membership inside a multi-tenant architecture with:

- Firebase Authentication
- household-scoped data
- owner / member / guest roles
- invite-by-code onboarding
- Firestore Security Rules
- real-time synchronization
- protected routes
- domain-oriented services

The production source code is intentionally private, but the public engineering case study documents the product, architecture and technical decisions.

**→ [View MadrigueritApp Showcase](https://github.com/botbotel/madrigueritapp-showcase)**
