## Proyecto destacado

### MadrigueritApp

Producto multiplataforma para la gestión compartida del hogar en **iOS, Android y Web**.

Combina tareas, calendario, compra, gastos y gestión de miembros dentro de una arquitectura multi-tenant con:

- Firebase Authentication
- datos aislados por hogar
- roles owner / member / guest
- incorporación mediante códigos de invitación
- Firestore Security Rules
- sincronización en tiempo real
- rutas protegidas
- servicios organizados por dominio

El código de producción se mantiene privado de forma intencionada, pero el case study público documenta el producto, la arquitectura y las decisiones técnicas.

**→ [Ver showcase de MadrigueritApp](https://github.com/botbotel/madrigueritapp-showcase)**
